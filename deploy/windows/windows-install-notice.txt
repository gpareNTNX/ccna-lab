CCNA EVE Lab Builder

This installer installs the CCNA EVE Lab Builder desktop application only.
It does NOT install, deploy or provision EVE-NG.

An existing, reachable EVE-NG server is required to use the lab-management features.
The application connects to that server using the EVE API and SSH.

Cisco IOSv/IOSvL2 images are not included.
You must supply images you are legally entitled to use.

The EVE-NG password is not persisted by the application.
